# 止损决策系统

先核对当前对象的真实时间线和边界，再决定是否降频、退出或停止联系。阶段、称呼和旧状态不能替代当前意愿。与情圣共用 `.cursor/skills/qingsheng/references/user-context.md` 的档案协议。

## 先分清三类信息

- **事实**：双方说了什么，谁主动，邀约是否被接受，是否已明确要求停止。
- **判断**：互动是否持续单向、双方期待是否一致；缺证据时说明不确定，不猜对方有别人、故意吊着用户或「其实在等你知趣」。
- **行动**：现在回应、等待、减少投入还是停止。不要为了得到拒绝次数或更多证据而追加邀约。

回复速度和消息长度要与两人平时节奏比较。一次慢回、发朋友圈却没回消息、称呼亲切或使用 emoji，都不足以判断喜欢或没兴趣。可以在事实不足时先降低投入，不必给对方的内心下结论。

## 止损等级

| `stoploss_level` | 证据与状态 | 当前行动 |
|---|---|---|
| 0 | 没有明确停止边界，现有互动仍有双向投入或只是正常波动 | 正常交流；不为维持关系强行加消息 |
| 1 | 持续投入失衡或意愿尚不清楚，仍需结合背景观察 | 暂停追问、减少单方面安排；不设固定几天后重发 |
| 2 | 持续单向联系、邀约不落实且无替代安排，或用户已决定不再投入 | 停止主动追求；不强制发收尾，不靠断联制造失去感 |
| 3 | 明确拒绝继续发展、要求停止联系、拉黑或持续越界 | 尊重拒绝、停止追求；要求停止联系或拉黑时不再追加任何消息 |

这些是行动分类，不是算分得出的心理诊断。说明所选等级的原话或行为依据；既不要求凑满几条才尊重拒绝，也不按固定小时数直接判停止。

**区分拒绝范围**：「这周不方便」首先表示这次安排不可行，不自动等同于永久拒绝；对方主动提供新日期时可以继续协调。「不要再约我」「不想发展关系」则不能靠换地点、继续玩笑或等待几天后重试绕过。

## 可以怎样回复

以下均为虚构例子，只按真实上下文选用：

- 对方说忙，用户还没回应：可以说「好，你先忙」，然后不再追问。
- 已有问题尚未回复：直接建议等待，不再补一条所谓低需求感话术。
- 对方明确说不合适、用户还未回应且没有停止联系要求：可以简短接受「明白，谢谢你直接告诉我」，之后停止追求。
- 对方说「别再联系我」或已拉黑：不再发送收尾，不换账号、不托人传话、不制造偶遇。

不编用户很忙、在健身或已有其他对象来体面退出。正常关心与真诚表达不等于失去价值；用户确实做错时可以承担责任，但不能以道歉为由反复打扰。

## 写回与后续

按统一协议记录判断依据、不确定点及下一步行动。只有新事实或判断变化时才更新；建议标记未执行，真实消息才进聊天记录。只读时不写，修改后再同步，失败就说明未同步。

退出后把精力放回自己的生活，允许失落，不设置必须几天振作或多久后重新联系的期限。以后若对方主动带来新的明确信息，可重新评估；不把对方可能回头当作停止的目的。
