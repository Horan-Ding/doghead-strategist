# 合并上游情圣更新

用户要求升级时才执行。本仓库的 qingsheng 是本地适配版，不能用上游文件直接覆盖；`VERSION` 记录上游来源版本，不代表本地规则未经修改。

1. 从 doghead-strategist 根目录运行 `./scripts/sync-skills.sh`，将上游候选下载到独立临时目录。该命令仅准备对比材料，不覆盖当前 Skill。
2. 比较候选与 `.cursor/skills/qingsheng/`，只合并用户需要的更新，保留证据判断、自然表达、拒绝边界及唯一 `GOUTOU_DATA_DIR` 档案协议。
3. 一起检查 stages、examples、自动、挽回及其引用，避免重新引入强制升阶、施压示例或全局档案目录。
4. `.agents/skills/` 如存在，核对本地变化后同步对应修改，不覆盖该目录独有的用户改动。
5. 检查引用、格式和典型场景后汇报实际合并结果；仅下载候选不能称为升级完成。不修改真实私有档案，不读写全局安装目录。
